微分方程模型在回答什么？
	“此刻变化得有多快？”
	因为一般来说微分方程的形式是dy/dt，你可以视为是变化率的形式
	要回答这个问题，我们一般需要知道三个要素：
		①状态
			现在有多少？在哪里？处于什么阶段？
		②机制
			增加/减少是由什么因素影响的、由什么因素组成了这个增加/减少
		③参数
			各机制的强度和时间尺度
		例如我要构建一个关于人口增长的微分方程模型，那么你需要知道
			1.状态：现在有多少人口，现在处于人口增长的什么阶段
			2.机制：我现在这么多人口会受到什么机制的影响，例如出生率、死亡率、迁入迁出率、自然灾害
			3.参数：上面机制里面的具体数值
	之后，我们用经典的微分方程的表达式
		从函数关系=》变化率关系
			$$ \frac{dy}{dt} = f(t,y ;\theta) , y(t_{0}) = y_{0}$$
			后一个条件是初值，而左边表示的是瞬时变化率
			![[Pasted image 20260821114707.png]]
	普通函数和微分方程
		普通函数 y = g(t)
			给定t，可以直接计算y
			公式本身就是完整的轨迹
			适合描述已知的静态关系
		微分方程 dy/dt = f(t,y)
			给定瞬时变化率
			还需要初值才能确定轨迹
			适合描述连续演化机制
	方程、初值、参数
		方程负责描述变化机制，机制描述当前状态如何决定下一刻的趋势
		初值负责指定哪一个点出发，将无数条可能轨迹缩小到一条
		参数负责控制增长、衰减、相互作用和时间尺度
	一阶、高阶和方程组
		一阶方程:y' = f(t,y)
		高阶方程：出现于y'',y'''，常见于运动学,例如速度和加速度
		但是一般来说高阶方程很难求解
			这时候我们需要引入状态变量，之后统一写成一阶系统，交给擅长求一阶导系统的求解器
	示例
		![[Pasted image 20260826221655.png]]
		根据关系式：dN/dt = rN，其中r是增长率，N是当前人口数量
		这张图代表的是：随着时间的变化，人口是怎么变动的
		r>0则增长，r<0则衰减
	微分方程构建的步骤
		第一步是构建状态：是谁在变化，单位是什么？
		第二步是确定尺度，也就是这个状态量是随着时间变化还是随着空间在变化
		第三步是把增加、损失、相互作用变成变化率，也就是写成单位时间贡献
		第四步是初值和参数的定义，这些定义需要从题设、数据/估计中补齐
	解析解和数值解
		解析解
			$$N(t) = N_{0}e^{rt}$$
			解析解结构清楚，便于证明和极限分析
			但是只适用于少数可解模型
			可作为数值结果的基准
		数值解
			$$\{t_{i},y_{i}\}$$
			适合非线性、方程组和分段机制
			可以得到离散时刻的近似轨迹
			但是必须配合误差和合理性检查
	以logistic人口增长模型为例
		$$ \frac{dN}{dt}  = rN \left( 1- \frac{N}{K} \right),N(0) = N_{0}$$
		其中:
			N(t):时刻t的人口数量
			r:人口增长率
			K:环境容纳量
			N0：初始人口数量(初值)
	常见的微分方程模型
		单体增长模型
			当前数量=》新增量
			例如出生率=》死亡率
			指数增长模型
				$$N' = rN$$
				指数增长通常假设：资源增长无上限
				其中N为状态量，N’ = dN/dt
				t为时间，r为净增长率(1/时间)
				适合早期/短时窗口，长期没有上限
			Logistic增长模型
				$$N' = rN\left(  1- \frac{N}{K} \right)$$
				其中N为状态量，N’ = dN/dt
				t为时间，r为净增长率(1/时间)
				K为环境容量
				1- N/K为资源限制项
				当N=》K时，N’=》0；K和N同单位
			Gompertz增长模型
				![[Pasted image 20260829153921.png]]
				同样是=》K，其表达式为：$$N' = rN \ln\left( \frac{K}{N} \right)$$
				Gompertz曲线相比于Logistic曲线要更早减速
				通过自然对数In(K/N)控制减速
			固定收益存在不可持续阈值
				![[Pasted image 20260829154239.png]]
				在Gompertz增长模型的基础上，增加一个H：$$N' = rN\left( 1- \frac{N}{K} \right)-H$$
				你可以解读为：实际增长量 = 自然增长量-人工捕捞量
				看图我们可以知道
					当自然增长量>固定收获时，种群是可以增长的
				H:单位时间内固定捕捞或收获的数量
					H<rK/4:两个正平衡
					H=rK/4:临界
					H>rK/4:无正平衡，长期枯竭
		资源限制
			例如logistic模型，人口增长到后期，增长速度变慢
			也就是密度越高，单位增长越慢
		外部移除
			捕捞、采收、药物/控制，例如上面的“固定收益存在不可持续阈值”模型
		种间作用
			例如竞争、捕食、互利/传播
			两种群竞争
				$$\begin{align*}
				N'_{1} = r_{1}N_{1}\left[ 1-\frac{N_{1}+\alpha_{1,2}N_{2}}{K_{1}} \right]\\
				N'_{2} = r_{2}N_{2}\left[ 1-\frac{N_{2}+\alpha_{2,1}N_{1}}{K_{2}} \right]
				\end{align*}$$
				状态变量：N1，N2两种群数量
					N’ = dN/dt
					t为时间
				自身增长
					r1,r2为内部增长率；K1，K2为环境容量
				种间竞争
					α：把异种数量折算为等效密度的竞争系数
				当竞争关系α大的时候，整个1-X项会变小，则单位个体增长率N1/N2变小
				或者当N1/N2自己变大的时候，整个1-X项会变小，则单位个体增长率N1/N2自己推动自己变小
			捕食者和被捕食者相互交错的模型——Lotka-Volterra模型
				![[Pasted image 20260829174550.png]]
				因果顺序：
					x：被捕食者数量
					y:捕食者数量
					x',y':各自对时间的变化率
					a：猎物增长率
					d:捕食者死亡率
					b:捕食强度
					c：摄食转化率
					x'(被捕食者的实际变化率) = ax-bxy=x(a-by)
						为什么xy可以相乘，因为如果猎物增加了，狩猎者也可以得到更多的食物
						当y> a/b时，x'反而变小；y< a/b时，x'变大
					y'(捕食者的实际变化率) = cxy-dy = y(cx-d)
						当x >d/c时,y'变大，x<d/c时，y'变小
		数据校准
		基于人群守恒的传播机制——SIR
			S、I、R:易感、感染、移出
			人数N:总人数;β:传播率;y:移出率
			S’、I、R':三类人数的变化率
			三式相加得S+l+R=N保持不变
			$$\begin{cases*}
			\frac{dS}{dt} = -\beta \frac{SI}{N},\\
			\frac{dI}{dt} = \beta \frac{SI}{N}-\gamma I,\\
			\frac{dR}{dt} =\gamma I
			\end{cases*}$$
			状态流动关系：$$S\xrightarrow{\frac{\beta SI}{N}} I \xrightarrow{\gamma I} R$$
			其中：
				βSI/N是单位时间内的新增感染人数
				γI是单位时间内从感染状态移出的人数
				R表示移出者，包括康复、隔离或其他不再参与隔离的人数，不一定只表示康复者
