聚类是无监督的；它不像分类，分类一般需要特征，还有一个输出=》==**每一个对象对应了一个特征和一个输出，一般是有标签的**==
聚类的无监督体现在：不依赖于预先已经定义好的类别
一个好的聚类应该达到：同类相聚，异类相斥，==**同类的对象尽可能相似，异类的对象尽可能不同**==
聚类方法
	K-means聚类
		K-means算法是==**典型的基于距离的聚类算法**==
		采用距离作为相似性的评价指标，即==**认为两个对象的距离越近，其相似度就越大**==。
		该算法认为簇是由距离靠近的对象组成的，因此把得到紧凑且独立的簇作为最终目标。
		K-mean算法步骤如下:
			==**(1)随机选取K个样本为中心==**
			**==(2)分别计算所有样本到随机选取的K个中心的距离==**
			**==(3)样本离哪个中心近就被分到哪个中心==**
			**==(4)计算各个中心样本的均值(最简单的方法就是求样本每个维度的平均值)作为新的中心==**
			**==(5)重复(2)(3)(4)直到新的中心和原来的中心基本不变化时，算法结束**==

		K-means的聚类公式用的是欧氏距离
			$$d(x_{i},c_{k}) = \sqrt{ \sum^n_{j=1} (x_{ij}-c_{kj})^2}$$
			其中：$$\begin{align*}
			d(x_{i},c_{k})是样本x_{i}到聚类中心c_{k}的距离\\
			x_{i}是第i个样本\\
			c_{k}是第k个聚类中心\\
			n是样本的特征数
			\end{align*}$$
			每个聚类中心是属于该聚类的所有样本均值：$$c_{k} = \frac{1}{|c_{k}|}\sum_{x_{i} \in c_{k}}x_{i}$$
			∀样本xi,计算其到聚类中心的距离，分配到距离最近的中心所在的类
		其中距离的指标我们也可以替换为以下距离
			曼哈顿距离(适用于高维空间而且特征之间独立的情况)：$$d(x_{i},c_{k}) = \sum^n_{j=1} |x_{ij}-c_{kj}|$$
			切比雪夫距离(适用于需要考虑最大差异的情况):$$d(x_{i},c_{k}) =\max_{j}|x_{ij}-c_{kj}|$$
			余弦相似距离(适用于文本数据/高维稀疏数据,主要作用于向量)：$$\cos (x_{i},c_{k} ) = \frac{\sum^n_{j=1}x_{ij}c_{kj}}{\sqrt{ \sum^n_{j=1}x^2_{ij} } \sqrt{ \sum^n_{j=1} c^2_{kj} }}$$
			杰卡德相似系数(适用于二值数据，例如0和1):
			$$\jmath (x_{i},c_{k}) = \frac{|x_{i} \cap c_{k} |}{|x_{i} \cup c_{k}|}$$
		聚类效果的衡量指标
			轮廓系数
				轮廓系数结合了凝聚度和分离度，取值范围为[-1,1]，==**值越大表示聚类效果越好**==
				$$S(i) = \frac{b(i)-a(i)}{\max (b(i),a(i))}$$
				a(i)代表样本到同类其他样本的平均值，b(i)为样本到最近聚类的平均距离
			Calinski-Harabasz指数 (Calinski-Harabasz Index) CH
				该指数计算簇间方差与簇内方差的比值，==**值越大表示聚类效果越好**==
				$$CH = \frac{tr(B_{k})}{tr(W_{k})} \times \frac{N-k}{k-1}$$
				其中N为样本总数，k是簇(类别的数量)，tr(Wk)为簇内散度矩阵的迹，tr(Bk)为簇间散度矩阵的迹
					假设一个簇里只有二维数据 (x1，x2)，有三个点：A=(1,2),B=(2,4),C=(3,3)
					它们的簇中心是：μ=(2,3)
					于是每个点相对于中心的偏离分别是：A−μ=(−1,−1);B−μ=(0,1);C−μ=(1,0)
					现在我们想回答一个问题：
						这三个点到底是怎么围绕 (2,3) 散开的？
						如果只看第一个维度（偏离值的x坐标相加）：(-1)^2+ 0^2+ 1^2 = 2
						这说明这个点在 x1​ 方向的离散程度为 2。
						再看第二个维度：(-1)^2+1^2+0^2 =2;说明在 x2​ 方向的离散程度也是 2。
						我们还想记录：x1​ 偏大的时候，x2​ 是不是也倾向于偏大？
						所以还会计算两个维度的“共同偏离”(也就是同一个偏移的两个坐标相乘)：-1*-1 +0* 1+1* 0 =1;
						于是这三个信息就被塞进一个矩阵：$$W = \begin{bmatrix}
						2,1 \\
						1,2
						\end{bmatrix}$$
						二维情况下，可以粗略记成：$$散度矩阵 = \begin{bmatrix}
						x_{1}的离散程度, (x_{1},x_{2}的共同变化) \\
						(x_{1},x_{2}的共同变化),x_{2}的离散程度
						\end{bmatrix}$$
						散度矩阵的定义：$$\sum_{i}(x_{i}-\mu) (x_{i}-\mu)^T$$
						==**取"迹"，就是离散程度相加**==
			Davies-Bouldin指数 (Davies-Bouldin Index) DB
				Davies-Bouldin指数衡量簇间的分离度和簇内的紧密度，==**值越小表示聚类效果越好**==
				$$DB = \frac{1}{k} \sum^k_{i=1} \max_{j≠i} \frac{\sigma_{i}+\sigma_{j}}{d(C_{i},C_{j})} $$
				σi是簇Ci的平均聚类，d(Ci,Cj)是簇Ci和Cj之间的距离

			例如轮廓系数法
				通过计算不同聚类数下的平均轮廓系数，选择平均轮廓系数最大的聚类数作为最佳聚类数。
				1.对于每个聚类数k，计算所有数据点的轮廓系数。
				2.计算平均轮廓系数。
				3.选择平均轮廓系数最大的k作为最佳聚类数
