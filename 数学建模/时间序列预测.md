传统的时序预测算法
	ARIMA算法
		AR模型
			该模型假设当期数值和前p期历史数值有关,建立前p期的历史值和第t期值有关的线性回归模型
			表达式为：$$x_{t} = \phi_{0}+ \phi_{1}x_{t-1}+\phi_{2}x_{t-2}+ \dots +\phi_{p}x_{t-p}+ \epsilon_{t}$$
			其中这些phi可以通过梯度下降法来求出
			最后的误差项的均值应当为0
		MA模型
			根据前t期的数据，未来t期的预测值=前t期均值+前q期的加权扰动；建立前q期的随机扰动和第t期值有关的线性回归模型
			表达式为：$$x_{t} = \mu+ \epsilon_{t}- \theta_{1}\epsilon_{t-1}-\theta_{2}\epsilon_{t-2} - \dots - \theta_{q}\epsilon_{1-q}$$
		ARMA模型
			假设当期数值不仅和前p期历史数值有关，而且和前q期的随机扰动有关,建立前p期的历史值、前q期的随机扰动并且以第t期值为因变量的线性回归模型
			表达式为：$$x_{t} = \phi_{0}+ \phi_{1}x_{t-1}+\phi_{2}x_{t-2}+ \dots +\phi_{p}x_{t-p}+ \epsilon_{t}- \theta_{1}\epsilon_{t-1}-\theta_{2}\epsilon_{t-2} - \dots - \theta_{q}\epsilon_{1-q}$$

	ARIMA算法的预处理
		拿到一个观察值序列之后，因为ARIMA对无趋势数据最擅长，所以先对观察值序列的==**纯随机性和平稳性**==进行检验
			平稳性指的是没有一个明显的上升/下降趋势
			从学术语言的角度，叫做这个数据的方差和均值基本不变
			![[Pasted image 20260816155154.png]]
		对于纯随机序列
			又称白噪声序列，==**序列的各项之间没有任何相关关系，序列在进行完全无序的随机波动**==
		对于数学建模来说，一般不会有纯随机序列，因为这种序列的数据没有什么预测价值
![[Pasted image 20260817154415.png]]
		一阶差分就是后一项-前一项
		如果一阶差分还是有趋势就二阶差分
		阶数一般≤3阶
		检验平稳性：用单位根检验
		检验随机性：用白噪声检验

		AR模型里面，最后的预测值由前p期决定，前p期也决定了那些参数
		MR模型里面，最后的预测值由前q期决定，q也决定了对应的参数
		ARMA就是由p和q同时决定，进而需要决定两个参数

				假设我们根据前p期历史值和前q期扰动预测出来这些数据（就例如这个绿线）
				然后，还没完，谁能保证你预测出来的数值和实际值能对应呢？
					我们先把这个问题转换一下：预测出来的数值和实际值能对得上=》==**意味着这个数据的残差已经没有时间序列信息了**==，不然的话你还要继续ARMA一边来拟合
					于是我们需要算出实际值（如果能得到的话）和预测值的差值，每一个差值，如果可以符合随机分布，那么这个差值是合格的，进而这个实际值也是合格的
		确定p和q怎么取值的方法——BIC
			BIC描述的是这样一个过程：先试很多组 (p,q) → 每组都拟合一个 ARMA/ARIMA → 分别计算 BIC → 选 BIC 最小的那一组。
			假设经过差分以后，我们已经确定了差分阶数为1
			那么现在还不知道 p,q。我们就设定一个合理的搜索范围，例如：p和q都分别尝试0到5
			于是计算机会尝试：ARIMA(0,1,0), ARIMA(1,1,0), ARIMA(0,1,1), ARIMA(1,1,1),…
			对每一种模型都重新估计 ϕ,θ 等参数，然后计算：$$BIC = k\ln n -2 \ln \hat{L}$$
				k=模型中需要从数据里估计的自由参数个数,例如有多少个前p项，那么就有多少个和p相关的系数；
				==**一般来说k=p+q+2,+2是因为前p项没有包括常数项，常数项一般也要估计上去；而前q的随机扰动又需要估计样本方差，所以+2**==
				回到这个公式，-2ln L这一部分是衡量数据拟合的程度，因为==**hat L是这个模型在参数估计完成之后得到的最大似然值。​**==
					因此，模型拟合得越好，L越大，-2ln L越小
				第二部分是kln n
					是对复杂模型的惩罚。p,q 越大，需要估计的 ϕ 和 θ 越多，因此 ==**k（自由参数） 越大，惩罚越严重。**==
						因为虽然说前p期越多越好，但是参数越多，你附加的随机性就越大
					n为样本总数
		ACF和PACF
			ACF/PACF 应该放在序列已经平稳之后，用来观察滞后相关结构，并初步判断 p,q
			也就是说，在BIC出现之前，一般用ACF/PACF确定p和q
			ACF 是 Autocorrelation Function，自相关函数。
				普通 Pearson 相关系数研究的是：XY之间的相关性
				但是时间序列数据只有时间和要研究的对象，那么我们“自己和自己比”，即：==**它自己往后错开几期，再和自己计算相关系数**==：
				$$\rho_{k} = Corr(X_{t},X_{t-1})$$
				其中 k 称为滞后阶数。
				例如研究每天的气温：X1​,X2​,X3​,…,X100​
				那么：ACF(1)=Corr(Xt​,Xt−1​)
				就是比较：==**(X2​,X3​,…,X100​)和(X1​,X2​,…,X99​)看看“今天”和“昨天”有多相关。**==
				同理：ACF(2)=Corr(Xt​,Xt−2​)是在问“今天和前天有多相关”。
