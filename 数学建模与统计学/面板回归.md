面板数据指的是==**多个研究对象在多个时间点进行重复观测所形成的数据。**==
优点：
	1、可以解决遗漏变量问题：那些无法用变量衡量的个体差异
		就是把这些隐藏起来的控制不了的变量表现了出来
	2、提供更多个体动态行为信息：从个体变异到时间变异
		每个样本之间是否不同，再到同一个研究对象，从这一期到下一期发生了什么变化。
	3、样本容量更大：提高估计精度

缺点：
	相较于截面数据容易带来自相关问题，相较于时间序列数据又容易带来异方差问题！
	面板数据多了个时间维度，就带来了自相关问题
	而相对于截面数据而言，不同样本本身就容易带来[[异方差问题]]

面板数据提供了以下两类不同的信息

|信息|比较的是什么？|企业研究中的例子|
|---|---|---|
|个体之间的差异，between variation|不同个体的平均水平|平均销售额较高的企业，平均投资额是否也较高？|
|个体内部的变化，within variation|同一个体在不同时期的变化|同一家企业的销售额增加时，其投资额是否也增加？|


极端的解决方法
	极端方法一：
		看成截面数据进行混合回归，假设每个个体都有完全一致的回归方程，但忽略了个体间不可观测的异质性。
	极端方法二：
		每个个体都设计一个单独的回归方程，但忽略了样本的共性，也很难有足够多的样本回归。

折中方法是允许个体回归方程有同样的斜率，但有不同的截距，来捕捉异质性。
	其中zi为个体不随时间变化的可观测特征，如性别等
	δ为其系数；
	ui表示个体不随时间变化的扰动项（无法观测）
	εit表示随时间变化的扰动项。

混合回归
	混合回归模型表达式
	$$\boxed{ y_{it} = \alpha+\mathbf x_{it}'\beta+\mathbf z_i'\delta+u_i+\varepsilon_{it} }$$
	这里的撇号表示转置，\mathbf x_{it}'\beta 就是把多个解释变量及其系数相乘后相加： $$\mathbf x_{it}'\beta = \beta_1x_{1,it}+\cdots+\beta_Kx_{K,it}. $$各项的含义如下：

| 项目               | 含义                  | 例子                 |
| ---------------- | ------------------- | ------------------ |
| \alpha           | 共同截距                | 所有个体共有的基准部分        |
| \mathbf x_{it}   | 可以随时间变化的可观测解释变量     | 培训时数、工作经验、企业销售额    |
| \mathbf z_i      | 观察期间不随时间变化的可观测特征    | 出生地、某些基期特征         |
| u_i              | 观察期间不随时间变化的不可观测个体因素 | 被假设为稳定的个人能力、企业管理特点 |
| \varepsilon_{it} | 随个体和时间变化的其余扰动       | 当期需求冲击、临时事件等       |
	为了推导固定效应，可以把所有不随时间变化的部分合并：$$a_i=\alpha+\mathbf z_i'\delta+u_i. $$
	于是模型变为：$$ \boxed{ y_{it}=a_i+\mathbf x_{it}'\beta+\varepsilon_{it}. } $$
	这就是“不同个体有不同截距，但有相同斜率”的基本形式。
	混合回归没有为每个人单独设置截距，而是直接估计：$$ y_{it} = \alpha+\mathbf x_{it}'\beta+\mathbf z_i'\delta+v_{it}, $$
	其中真实的复合误差为：$$v_{it}=u_i+\varepsilon_{it}. $$
	因此，问题取决于：**放进误差项的 u_i，是否与解释变量相关。**
	先看只有一个解释变量、暂不包含 \mathbf z_i 的情况：$$y_{it}=\alpha+\beta x_{it}+u_i+\varepsilon_{it}. $$
	含截距的混合 OLS 斜率为： $$\hat\beta_{\mathrm P} = \frac{\sum_{i,t}(x_{it}-\bar x)(y_{it}-\bar y)} {\sum_{i,t}(x_{it}-\bar x)^2}. $$
	将真实模型代入，可以得到：$$ \boxed{ \hat\beta_{\mathrm P}-\beta = \frac{\sum_{i,t}(x_{it}-\bar x)u_i} {\sum_{i,t}(x_{it}-\bar x)^2} + \frac{\sum_{i,t}(x_{it}-\bar x)\varepsilon_{it}} {\sum_{i,t}(x_{it}-\bar x)^2}. } $$
	这两个分式分别显示了个体因素和时变扰动如何进入估计误差。

假设所有个体有同样的回归方程，像以往截面数据一样回归：
Yit=α+Xit’β+zi’δ+εit
但实际上方程可能是这样的：
Yit=α+Xit’β+zi’δ+ui+εit
忽略了一些个体无法观测、或者无法度量的因素！
而且由于不同时期同一个个体之间存在相关性，这个回归会存在自相关问题！
固定效应模型：
Yit=α+Xit’β+zi’δ+ui+εit
把这个方程两边对时间取平均数：

在相减的时候，把不受时间变化的δ和ui减去了，那么我们得到的就是受时间变化的

实际上，这种回归方式与在原方程中加入个体虚拟变量的回归结果是完全相同的，只要控制每个人的特点（n-1个个体，没有截距项时控制n个个体），相当于把ui控制了，这种方法称为（Least Square Dummy Variable Model，LSDV）：
xi:reg 因变量 自变量 i.控制变量......
LSDV会损失自由度
	因为固定效应模型减了均值，形成了离差形式，或者通过LSDV方法加入了大量变量，所以对模型自由度造成了很多损失。

以上个体固定效应模型解决了不随时间变化但随个体变化的遗漏变量问题，类似地，可以引入时间固定效应，解决不随个体变化，但随时间变化的变量，如经济周期等：
Yit=α+Xit’β+zi’δ+ui+λt+εit

如果满足ui和其他解释变量不相关，则固定效应模型不是最有效的回归方法（估计系数方差不是最小）
此时可以选择随机效应模型进行估计(但是一定要满足ui和其他解释变量不相关，否则跑出来的情况不好)，得到的回归系数记为βRe。
然而，尽管βRe方差更小，但其系数可能不是一致的（有偏），βFe却一定是无偏的。
	因为在固定效应模型里面，zi’δ+ui是固定的
	那么如果我们让他变化了，那么我们就可以的得到随机效应模型

可以通过豪斯曼检验考察能否采用随机效应模型回归，其原理是利用βFe和βRe作比较而进行的卡方分布检验，如果差异很大，==**则拒绝H0：ui与其他解释变量不相关，应该采用固定效应模型。**==
	豪斯曼检验的原理就是直接比较两者之间的差异
	如果βFe和βRe差异显著，那么取用βFe；因为βFe是无偏的；
	但是如果差异不显著，那么用βRe比较有效
	怎么比较的：用:$$H_{0} : \beta_{Fe} -\beta_{\mathrm{Re}} =0$$
