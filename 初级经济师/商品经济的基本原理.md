商品的基本属性和本质特征
	商品的使用价值和价值
		商品是用来交换的劳动产品，具有使用价值和价值两种属性
		使用价值
			商品具有的效用，换句话说，就是==**能满足人类某种需要的属性**==
			例如骑自行车，能骑行，就是能满足我们人类的某种需要
			又例如面包
			==**使用价值属于商品的自然属性**==，是自然而然的
			和生产力一样，==**是反映人与自然的关系**==
			特征：质不同，从而使用价值之间很难相互比较
		价值
			==凝结在商品中的一般人类劳动，是抽象出来的，和劳动有关的商品价值==
			价值是==**商品所特有的本质属性和社会属性**==
			==**价值体现了商品生产者之间的社会经济关系**==
			而且这样的价值具有可比性，因为是抽象出来的跟人的劳动有关的，方便后续交换
			特征：质相同，量可比
	商品是使用价值和价值的矛盾统一
		①使用价值和价值统一于商品之中，缺一不可
			因为1.使用价值是价值的物质载体，没有使用价值的物品没有价值，进而就不是商品
			2.价值是商品的本质属性，仅仅有使用价值但是没有价值的物品也不是商品
				例如你自己用旧零件组装了一台手机，自己每天使用；这就不是商品，因为仅有使用价值，但是没有经过==**交换**==
				又例如空气
		②使用价值和价值之间也是互斥的
			商品的生产者和消费者都不能既占有商品价值又占有商品的使用价值
				因为商品一定会经过交换；就例如你不能要这个产品（使用价值），但是又要这个产品对应的钱（价值）
			解释：==**只有通过商品交换，生产者让渡了商品的使用价值进而实现了价值==**
				**==而消费者支付了商品本身的价值而获得了使用价值**==
	交换价值
		一般来说，商品的交换，是用一种使用价值和另一种使用价值相交换，那么我们需要澄清什么是“交换价值”，也就是==**交换商品本身的价值**==
		==**一种使用价值和另一种使用价值相交换的量的关系/比例**==
		相互关系
			A.使用价值是商品交换价值和价值的物质载体
			B.商品交换的比例==**取决于商品本身价值的大小**==
			C.==**价值是交换价值的基础/内容，交换价值是价值的表现形式**==
				这里的意思指的是，虽然商品交换表面上是在交换使用价值，但实际上是在交换价值
		==**交换价值 是 商品交换时表现出来的比例关系。“交换价值”既不是“交换 + 价值”，也不是“交换行为产生的价值”**==
			==**交换价值本质上是比例关系**==而不是价值/使用价值
	劳动的二重性
		上面我们知道了商品有两个价值+一个动态的价值（交换价值）
		但是为什么会这样呢？这是劳动的二重性决定的，也就是劳动分为抽象劳动和具体劳动
		具体劳动
			在一定具体形式下进行的劳动
			属性：创造了商品的使用价值；就例如生产自行车和生产面包，具体劳动的形式是不一样的
			但是==**具体劳动不是使用价值的唯一来源**==，例如空气就不需要具体劳动
		抽象劳动
			==**从劳动具体形式里面抽象出来的一般人类劳动**==
			属性：创造价值，并且是==**形成商品本身价值的唯一来源**==
			而且是具有可比性的
		具体劳动和抽象劳动的对立统一
			①具体劳动和抽象劳动在时间和空间上是统一的
				商品生产者在付出具体劳动的同时也付出了抽象劳动
				==**具体劳动和抽象劳动是生产商品的同一劳动过程中的两个不同的方面，而不是两种劳动，更不是两次劳动**==
			②具体劳动和抽象劳动之间是存在差别的
				就是前面的内容
	商品的价值量
		商品价值量的决定
			商品的价值是质和量的统一
			因为商品的价值是凝结在人类的一般劳动中的，因此商品的价值量是凝结在一般人类劳动的量
			商品价值量==**是由生产商品的社会必要劳动时间决定的**==，不是由个别生产者生产某种商品所耗费的个别劳动时间决定的
			社会必要劳动时间
				在社会正常的生产条件下，==**在社会平均劳动熟练程度和劳动强度下**==制造某种使用价值所需要的劳动时间
				特征
					==**社会必要劳动时间不是固定不变的，它随着劳动生产率的变化而变化**==，进而使价值量也发生相应的变化
					例如科技的进步
			商品的社会价值（其实就是商品本身价值在社会上的强调）
				==**由社会必要劳动时间所决定的价值量，是商品的社会价值**==
				==**商品的社会价值还是商品交换的依据**==
					因为==**商品的交换价值是商品价值的一种表现形式**==
			为什么是社会必要劳动时间决定了商品的价值量，而不是抽象劳动
				==**抽象劳动决定“价值的本质来源”，社会必要劳动时间决定“价值量的大小”。**==
				决定商品价值量的不是某个生产者实际花费多少劳动，而是社会平均条件下生产该商品所需要的劳动量。
				否则，不符合商品经济的规律
				你可以理解为：==**社会必要劳动时间是衡量抽象劳动的计量单位**==
			劳动生产率
				劳动者==**生产某种商品的使用价值**==的效率
				表示方法
					==**单位时间内生产的产品数量==**
					**==生产单位产品所消耗的劳动时间**==
				影响和决定因素
					(1)劳动者的平均熟练程度
					(2)生产过程的社会组织形式
					(3)科学技术发展及其在生产中的应用
					(4)生产资料的质量和效能
					(5)自然条件
				结论
					==**单位商品的价值量与包含在商品中的社会必要劳动量成正比**==，==**与生产该商品的劳动生产率成反比**==。
货币的产生和职能
	货币的产生和本质
		商品价值的表现形式
			在商品经济中，因为商品的交换价值是商品价值的表现形式。而==**商品的价值通过货币来表现**==
			==**货币是价值形式发展的最高阶段，是固定充当一般等价物的特殊商品。**==
			这里需要和使用价值区分一下：使用价值由具体劳动创造，而使用价值的来源不唯一，可以是具体劳动，也可以只是自然的属性
			==**商品价值的表现形式就是价值形式**==
			> 交换价值是商品价值表现出来的==**具体交换比例**==；价值形式是商品价值==**借助其他商品表现出来的形式**==。
		价值形式发展的四个阶段
			简单/偶然的价值形式
				==**一种商品的价值偶然、个别地表现在另一种商品上**==
				例如一头牛交换两罐肉
			扩大的价值形式
				一种商品的价值表现在和它相交换的一系列商品上
				例如一头牛可以换2头羊，可以换3头猪
			一般价值形式
				==一切商品的价值都统一表现在==从商品世界分离出来==**充当一般等价物的某种商品上**==
				此时的一般等价物是变化的，可以是金银以外的东西
			货币价值形式
				==**一般等价物最终固定在一种商品上（例如金银），此时这种商品就成为货币**==
			那么，货币的本质就是==**固定地充当一般等价物**==，体现商品生产者之间的社会经济关系
		货币的职能
			指的是货币在社会经济生活中的作用
			==**是由一般等价物的本质决定的**==，是货币本质的具体体现
			货币的基本职能
				价值尺度
					指的是==**货币充当表现和衡量一切商品价值量大小的尺度**==（就例如1,2，5,10元）
					==**货币充当衡量商品价值量的尺度是外在的==**
					**==衡量商品价值量的内在尺度是社会必要劳动时间**==（也就是社会必要劳动时间决定了商品价值量）
					在执行价值尺度的职能时，货币可以只是观念上的货币，例如Bancor班科，又例如价格标签
				商品价值的货币表现就是商品的价格
					已知货币是固定充当一般等价物的商品
					在这里的意思指的是，==**当价值形式发展到货币形式以后，商品价值的一种特殊表现之一是货币表现**==
						==**商品价值是价格的基础，价格是价值的货币表现**==
					当价格和价值一致时，商品的价格主要取决于商品价值和金属货币价值
						注意这里指的是==**价格取决于谁，而不是价值取决于谁**==
						==**商品价格和商品价值的变化成正比==**
						**==商品价格和货币价值的变化成反比**==
							==例如一个自行车=1000元￥，当商品的真正价值上升时，所需要付出的价格上升==
							==当货币的真正价值上升，即货币更值钱的时候，商品的价格下降==
							注意，==**这里的商品价值和货币价值是自变量而不是因变量，和通货膨胀无关（因为通货膨胀以商品价格的普遍变动为基础）**==
				流通手段
					==**是货币充当商品交换媒介的职能**==
					作为流通手段的货币，必须是现实的货币，但只是象征性地存在，不一定是足值的货币
						注意，这里的足值还是不足值，就例如黄金是足值的货币。但是纸币不是，一张纸就是象征，例如一张100元纸币，==**造出这张纸币的价值≠这个货币所象征的价值**==
					==**纸币一类的价值符号就代替了真实货币执行流通手段的职能**==
			货币的其他职能
				贮藏手段
					指的是==**货币退出流通领域**==，==**被当做独立的价值形式和社会财富的一般形式而保存起来**==的职能
					充当贮藏职能的货币必须是足值的，这样采用保值甚至是增值的功能
						例如黄金
					在金属货币流通的情况下，执行贮藏手段职能的货币可以自发==**调节流通中的货币量**==
						因为贮藏会导致退出流通领域
				支付手段
					(1)货币被用来==**支付商品赊买过程中的延期支付，以及用来支付债务、租金、利息、工资**==等的职能
					(2)==暂时解决了由于缺乏现金而不能及时购买商品的矛盾==，==**减少了流通中所需要的货币量**==，促进了商品生产和商品交换的发展。
					(3)在==**商品生产者和消费者之间形成了错综复杂的债权债务关系**==，进一步扩大了商品经济的矛盾，增大了发生经济危机的可能性。
					口诀：租息薪债（支付手段的考察重点在(1)）
				世界货币
					(1)世界货币是指==**货币越出国内流通领域**==，在世界市场上执行一般等价物的职能。
					(2)==**执行世界货币职能的货币，一般是贵金属的自然形式**==。
					(3)在现实生活中，少数发达国家的纸币，也在定程度上起着世界货币的作用。
						例如欧元，美元
					世界货币的职能
						1作为国际购买手段，购买外国商品。
						2作为国际支付手段，平衡国际贸易差额。
						3作为社会财富的代表，由一国转移到另一国。（作为贮藏手段）
		货币的流通规律
			一定时期内==**商品流通中所需要的货币量**==的规律
			基本内容
				商品流通过程中需要的货币量，==**由流通中的商品价格总额和货币流通的平均速度决定**==
				费雪方程式：MV=PT
					其中M是流通中所需要的货币量，V是货币流通速度
					就例如说，现在市面上流通的纸币价值有1亿，假设流通了1万次，那么整体流通价值：1亿* 1万
					P是商品价格水平，T是待流通的商品数量
					那么==**等式右边就是待流通的商品的总价值/待流通商品价格总额**==
					那么==**流通货币总价值=交易商品总价值**==就组成了费雪方程式
				那么商品流通所需要的货币量的决定因素就是：
					待流通的商品总量
					商品的价格水平
					货币流通速度
			纸币流通规律
				纸币的发行量要以流通中需要的金属货币量为限
				通货膨胀
					==**纸币发行量>流通中所需要的金属货币量，则纸币贬值物价上涨**==
				通货紧缩
					纸币发行量<流通所需货币量，货币价值含量上升，物价下降
价值规律及其作用
	价值规律
		社会必要劳动时间决定商品价值量(举一反三：商品价值量的外在表现是价格)
		商品交换==**以价值量为基础**==，实行等价交换
		价值规律是商品经济的基本规律
		表现形式
			A.==**价值规律通过价格运动对生产和交换活动起支配作用**==
			B.商品价格==以商品本身价值为基础==，但是==**其价格还会受到市场供求关系的影响**==
				==**供过于求时，商品卖不出去，那么此时价格<价值==**
				**==供不应求时，商品来不及生产，那么此时价格>价值**==
			C.尽管商品的价格和价值之间存在不一致，但这不违背价值规律
				![[Pasted image 20260807124901.png]]
				就像这张图一样，价格在价值上下来回波动回归
				那么，（1），从同一商品交换的总体和较长时期来看，其价格上涨时高于价值的部分和下落时<价值的部分往往可以相互抵销，因而一定时期内商品的平均价格与价值是趋于一致的。
				(2)从总体上来讲，==**一定时期内市场上商品的总价格和总价值应是大体=的。**==
		价值规律的作用
			调节资源配置和经济活动
				价值规律==通过价格机制，调节在社会生产各部门的生产资料和劳动力==
				价值规律的这样的调节是一种==**事后调节**==
			刺激商品生产者改进技术，提高劳动生产率，推动社会生产力发展
				率先提高劳动生产率和改进生产技术的商品生产者，它们生产商品的==**个别劳动时间<社会必要劳动时间**==
				进而==**商品的个别价值<社会价值**==，进而在竞争中处于优势
					这里的价值不是使用价值，是==**以价格为外在表现，凝结了人类劳动的商品本身的价值**==
					而且这里说的是，劳动者在这里付出的个别价值低，但是仍然可以以社会价值来卖出
			促进市场竞争，实现优胜劣汰

支付手段和流通手段最主要的区别在于：
==**支付手段是债权债务关系，但是流通手段通常是即时支付**==
商品已经完成交换，之后的钱是在偿还债务。这是一种时间分离，也是债权债务关系
合同：
- 首付15万元
- 银行贷款85万元
所以，你既支付了，得到了房子，只不过对于贷款来说是债权债务关系，但是首付不是
而银行放贷直接给你买房，也是流通手段

总之，即时交易的一手交钱一手交货的买卖肯定是流通手段

D.简单劳动与复杂劳动的矛盾
E.脑力劳动与体力劳动的矛盾

商品内部有哪些基本矛盾。

商品具有两个属性：

- **使用价值**：商品能够满足人的某种需要（自然属性）
- **价值**：凝结在商品中的无差别一般人类劳动（社会属性）

生产商品的劳动也具有二重性：

- **具体劳动**：生产某种具体使用价值的劳动，例如木匠做桌子、裁缝做衣服
- **抽象劳动**：撇开劳动具体形式后，形成商品价值的一般人类劳动

另外，由于商品生产是私人生产：

- **私人劳动**：商品生产者独立完成自己的生产活动
- **社会劳动**：商品生产实际上需要得到社会承认，商品才能交换出去
货币的出现，使整个商品世界分成了两极:
一极是商品，它们都有特殊的、各不相同的使用价值;
一极是货币，它是一切商品价值的代表。
因此，商品内部的使用价值和价值的矛盾、具体劳动和抽象劳动的矛盾、私人劳动和社会劳动的矛盾，就发展成为商品与货币的外部对立。

## 2. 为什么不是支付手段？

支付手段的核心是：

> 商品买卖和货币支付在时间上分离。

也就是：

先取得商品或服务，之后再付款。

例如：

### 买房贷款：

今天：

```
银行 → 贷款给你
你 → 买房
```

以后：

```
你 → 银行还贷款
```

这里货币不是用于即时交换，而是在履行债务。

所以是支付手段。
